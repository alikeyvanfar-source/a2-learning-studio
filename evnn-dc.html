          Step 2 of 6 · Required

          Case studies

          Run the EVT and MCDM analysis on three data center cases. The case figures are illustrative teaching parameters, not company data.

          Choose a case

          Select a case, then run its analysis. Analyze all three to compare them in a TOPSIS ranking.

          TOPSIS ranking of the alternatives you analyzed

          TOPSIS compares every analyzed alternative on the six category scores, using the category weights. The best alternative has the shortest distance to the ideal and the longest distance to the worst.

            Step 4a of 6 · Optional

            MCDM dashboard

            See how an analysis is built from its weighted criteria, test it under uncertainty with a Monte Carlo simulation, and compare all alternatives.

            Monte Carlo uncertainty simulation Optional

            Each run varies eight inputs around this project's values (climate risk, water risk, PUE, grid reliability, supply-chain risk, power cost, renewable share and regulatory risk), widened by the scenarios below, and re-scores all criteria. Every run uses a new random seed, which is recorded so the result can be reproduced.

            Criteria weights and scores (AHP-inspired)

            Category weights sum to 100%; sub-criterion weights sum to 100% within each category. Scores run from 0 (worst) to 100 (ideal).
